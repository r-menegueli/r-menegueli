# Olá, eu sou Rogério Menegueli

Sou estudante de Engenharia Elétrica no IFSP, campus Sertãozinho, com conclusão prevista para dezembro de 2026. Neste perfil reúno projetos acadêmicos e estudos pessoais em documentação elétrica, automação, eletrônica, simulação e software.

Os repositórios registram o que foi desenvolvido e os limites de cada estudo. Os projetos de CAD, BIM e hardware são conceituais; não estão liberados para obra, instalação ou fabricação.
